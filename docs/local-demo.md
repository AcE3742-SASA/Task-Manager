# 로그인 없는 개발용 테스트

```sh
npm run dev:demo
```

http://127.0.0.1:5183 에서 예시 과제 5개·과목 3개로 시작한다. 테마 선택, 할 일 추가·수정·완료·삭제, 달력·시간표를 실제 앱 화면으로 테스트할 수 있다. 변경 사항은 이 주소의 브라우저 localStorage에만 저장된다.

빌드 결과를 확인하려면 다음 두 명령을 순서대로 실행한다.

```sh
npm run build:demo
npm run preview:demo
```

테스트 빌드는 http://127.0.0.1:4183 에서 열린다. 탭 제목의 `[DEV]`와 프로필의 `개발용 테스트`로 구별한다. 처음에는 Glassmorphism 라이트 모드이며, 이후에는 마지막 선택이 복원된다. 초기 예제로 되돌리려면 해당 주소의 사이트 데이터를 지우고 새로고침한다.

`--mode demo`에서만 Firebase 모듈을 `src/dev`의 로컬 구현으로 연결한다. 실제 계정·클라우드 동기화·푸시·서비스워커를 사용하지 않는다. `npm run build`의 일반 빌드에는 데모 계정과 저장소가 포함되지 않는다. `dist-demo`는 로컬 확인용이다.

검증은 실행 중인 테스트 빌드에 `node scripts/check-demo.mjs`를 사용한다. 별도로 설치된 Playwright는 `PLAYWRIGHT_MODULE`에 모듈 경로를 지정할 수 있다. 새 브라우저 프로필에서 로그인 없이 진입, 네 테마 선택·복원, 할 일 생성·완료·수정·삭제를 확인하고 외부 요청이 없는지 검사한다.

`node scripts/check-glass-surfaces.mjs`는 320px에서 네 테마 × 두 밝기의 과목 배지 색을 확인하고, 월간 달력의 해당 월 날짜·요일 정렬·월 이동, 칸 전체 메뉴 하이라이트와 고정 반사, 마우스/터치 빠른 생성, 입력창 수정·저장·복원, FocusDock 완료·접기를 확인한다. `THEME_QA_BROWSER=webkit`으로 Safari 계열 엔진을 선택할 수 있다. Chromium에서는 투명도 줄이기 대응도 검사한다.
